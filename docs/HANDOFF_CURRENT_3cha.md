# LOVE STORY MV — Claude Handoff / Current State

## 0. 목적

이 문서는 **Claude가 지금까지의 대화 맥락을 전혀 모른다는 전제**로 작성된 현재 작업 인수인계 문서다.

Claude는 먼저 현재 편집본 영상을 직접 확인한 뒤, **이미 완성된 구간은 건드리지 않고 검은 빈 구간/미완성 구간만 채우는 것**을 기본 원칙으로 한다.

현재 기준 편집본:

- `/mnt/data/3차.mp4`

중요:
- 아래 타임코드는 `3차.mp4` 기준이다.
- 이후 사용자가 편집을 더 했다면 타임코드가 조금 달라질 수 있으므로, **작업 시작 전에 반드시 실제 영상을 다시 스캔해서 검은 구간과 앞뒤 장면을 확인한다.**
- 기존 완성 장면은 임의로 재편집하거나 교체하지 않는다.

# 1. MV 전체 방향

## 핵심 컨셉

밝고 로맨틱한 K-pop 걸그룹 MV.

전체 색감은:
- BLUE 계열의 깨끗한 로맨틱 톤
- 자연스러운 피부
- 부드러운 bloom
- 과한 HDR 금지
- 지나친 파스텔 필터 금지
- 지나치게 뽀얗거나 플라스틱 같은 피부 금지
- 실사에 가까운 고급스러운 K-pop MV 질감

최근에는 꽃밭/온실 장면이 이미 충분히 많아졌기 때문에,
**앞으로 새로 만드는 컷은 도시 / 실내 / 야경 / 생활 공간 / 디테일 컷을 우선한다.**
